═══════════════════════════════════════════════════════════════════════════
                        COMMON MISTAKE TO AVOID
═══════════════════════════════════════════════════════════════════════════

❌ WRONG: Push SCSS to Salesforce
   testScssComponent.scss → Flosum → Salesforce
   Result: Component has NO STYLES (Salesforce ignores SCSS)

✅ CORRECT: Compile first, push CSS
   testScssComponent.scss → Compile → testScssComponent.css → Flosum → Salesforce
   Result: Component is properly styled
